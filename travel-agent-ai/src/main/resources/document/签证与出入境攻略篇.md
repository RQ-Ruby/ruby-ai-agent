# 签证与出入境攻略篇

## 第一部分：签证办理通用流程

### 1.1 签证类型与选择

|签证类型|适用场景|停留时间|办理难度|
|---|---|---|---|
|**旅游签证（L签）**|旅游、观光、探亲访友|通常15-90天|较低|
|**商务签证（M签）**|商务考察、会议、洽谈|通常30-180天|中等|
|**学生签证（F签）**|留学、交流学习|根据学习时长|较高|
|**过境签证**|经停第三国前往目的地|通常24-72小时|低|
|**电子签证（E-visa）**|在线申请，无需邮寄护照|通常15-90天|低|

### 1.2 签证办理10步标准流程

1. **确定目的地和签证类型**：根据旅行目的和目的地选择合适的签证类型

2. **查询签证要求**：访问目的地国家驻华使领馆官网，查询最新的签证要求和材料清单

3. **准备申请材料**：按照要求准备所有申请材料，确保材料真实、完整、有效

4. **填写申请表**：在线填写或下载填写签证申请表，确保信息准确无误

5. **预约签证时间**：在线预约签证申请时间或递交材料时间

6. **递交申请材料**：按照预约时间前往签证中心或使领馆递交申请材料

7. **缴纳签证费用**：缴纳签证申请费和服务费

8. **生物信息采集**：部分国家需要采集指纹和照片

9. **等待签证审批**：等待签证审批结果，通常需要3-30个工作日

10. **领取签证**：签证审批通过后，领取护照和签证，检查签证信息是否正确

### 1.3 通用申请材料清单

- **护照**：有效期不少于6个月，至少有2页空白签证页

- **签证申请表**：完整填写并签名

- **照片**：符合目的地国家要求的近期免冠彩色照片

- **身份证明**：身份证、户口本复印件

- **旅行证明**：往返机票预订单、酒店预订单、行程单

- **资金证明**：银行流水、存款证明、在职证明、学生证明等

- **其他材料**：根据不同国家和签证类型的要求提供

## 第二部分：主要国家/地区签证政策（2026最新）

### 2.1 互免签证国家/地区

- **互免普通护照签证（30天为主）**：新加坡、马来西亚、泰国、阿联酋、塞尔维亚、毛里求斯、斐济、卡塔尔、白俄罗斯、波黑

- **俄罗斯**：互免签证至2026年9月14日，每次停留不超过30天，每年累计不超过90天

- **巴西**：2026年5月11日起互免签证，每次停留不超过30天，每年累计不超过90天

- **欧盟申根区**：法国、德国、意大利、西班牙、荷兰、瑞士等27国，持普通护照可免签入境，每次停留不超过90天，每180天累计不超过90天

- **英国**：2026年1月1日起互免签证，每次停留不超过6个月

### 2.2 单方面免签国家/地区

- **亚洲**：韩国济州岛（30天）、日本（15天）、菲律宾（14天，仅限马尼拉/宿务）、伊朗（21天）、印度尼西亚（30天）

- **非洲**：摩洛哥（90天）、突尼斯（90天）、塞舌尔（30天）、毛里塔尼亚（30天）

- **美洲**：厄瓜多尔（90天）、海地（90天）、牙买加（30天）、多米尼克（30天）

- **大洋洲**：萨摩亚（60天）、斐济（30天）、瓦努阿图（30天）

### 2.3 热门国家电子签证政策

- **越南**：电子签E-visa单次25美元90天，多次50美元90天，支持30多个海陆空口岸入境

- **土耳其**：电子签60美元，有效期180天，单次停留不超过30天

- **印度**：电子签80美元，有效期1年，多次入境，每次停留不超过90天

- **澳大利亚**：电子旅行许可（ETA）20澳元，有效期1年，多次入境，每次停留不超过3个月

- **新西兰**：电子签证165新西兰元，有效期5年，多次入境，每次停留不超过3个月

### 2.4 热门国家签证注意事项

- **美国**：

    - 所有持10年有效期B1/B2签证的中国公民，赴美前必须在EVUS系统登记信息

    - 2026年世界杯期间，部分B1/B2签证申请人需缴纳5000-15000美元不等的可退还保证金

    - 面签时需准备充分的材料，证明自己有牢固的约束力，会按时回国

- **日本**：

    - 2026年1月1日起，中国公民可免签入境日本15天

    - 如需停留超过15天，需提前申请签证

- **泰国**：

    - 2026年继续对中国公民实行免签政策，每次停留不超过30天

    - 入境时需携带足额现金证明（个人10000泰铢，家庭20000泰铢）

- **新加坡**：

    - 互免签证，每次停留不超过30天

    - 入境时需填写电子入境卡

## 第三部分：出入境流程与注意事项

### 3.1 出境流程

1. **办理值机**：提前2-3小时到达机场，凭护照办理值机和托运行李

2. **边防检查**：填写出境卡（部分国家已取消），接受边防检查，出示护照、签证、机票

3. **安全检查**：接受安全检查，禁止携带易燃易爆、管制刀具等违禁物品

4. **候机与登机**：在指定候机区候机，听到登机通知后排队登机

### 3.2 入境流程

1. **边防检查**：下飞机后前往边防检查处，出示护照、签证、入境卡、往返机票、酒店预订单

2. **提取行李**：通过边防检查后，前往行李提取处提取托运行李

3. **海关检查**：接受海关检查，申报携带的物品，禁止携带违禁物品

4. **入境**：通过海关检查后，即可入境

### 3.3 出入境禁止携带物品

- **禁止出境物品**：

    - 文物、珍贵动植物及其制品

    - 涉及国家秘密的文件、资料和其他物品

    - 濒危和珍贵动植物及其种子、繁殖材料

    - 管制刀具、枪支弹药、易燃易爆物品

    - 毒品、精神药品、麻醉药品

- **禁止入境物品**：

    - 新鲜水果、蔬菜、肉类、蛋类、奶制品等动植物产品

    - 种子、苗木、土壤

    - 毒品、精神药品、麻醉药品

    - 枪支弹药、管制刀具、易燃易爆物品

    - 反动、淫秽、色情的印刷品、音像制品

### 3.4 海关申报规定

- **中国出境申报**：

    - 携带人民币现钞超过20000元，或外币现钞折合超过5000美元，需向海关申报

    - 携带文物、金银制品、电子产品等贵重物品，需向海关申报

- **外国入境申报**：

    - 不同国家对现金携带的规定不同，通常超过10000美元或等值货币需申报

    - 携带食品、药品、动植物产品等需向海关申报

    - 禁止携带违禁物品入境，否则将被没收并罚款

## 第四部分：常见问题与解决方法

### 4.1 签证被拒怎么办

- **了解拒签原因**：仔细阅读拒签信，了解拒签的具体原因

- **准备补充材料**：针对拒签原因准备补充材料，证明自己的情况

- **重新申请签证**：在规定的时间内重新申请签证，避免重复提交相同的材料

- **寻求专业帮助**：如果自己无法解决，可以寻求专业签证中介的帮助

- **考虑其他目的地**：如果多次被拒，可以考虑更换其他目的地

### 4.2 签证丢失或被盗怎么办

- **立即报警**：向当地警方报案，取得报案证明

- **联系中国驻外使领馆**：向中国驻外使领馆申请补发护照或旅行证

- **联系签证颁发国使领馆**：向签证颁发国使领馆申请补发签证或出具证明

- **调整行程**：根据实际情况调整行程，避免不必要的损失

### 4.3 入境被拒怎么办

- **保持冷静**：不要与海关人员发生冲突，保持冷静和礼貌

- **了解拒入境原因**：询问海关人员拒入境的具体原因

- **配合海关工作**：按照海关人员的要求配合工作

- **联系中国驻外使领馆**：寻求中国驻外使领馆的帮助

- **安排返程**：如果无法入境，尽快安排返程

### 4.4 护照过期怎么办

- **提前办理护照换发**：护照有效期不足6个月时，提前到当地出入境管理部门办理换发

- **境外护照过期**：如果在境外护照过期，联系中国驻外使领馆申请补发护照或旅行证

- **注意事项**：护照过期后不能出境，必须提前换发

## 第五部分：实用工具与信息

### 5.1 官方信息查询渠道

- **中国领事服务网**：http://cs.mfa.gov.cn/，提供各国签证信息、领事保护信息

- **目的地国家驻华使领馆官网**：查询最新的签证政策和申请要求

- **国家移民管理局官网**：https://s.nia.gov.cn/，提供出入境管理信息和服务

- **海关总署官网**：http://www.customs.gov.cn/，提供海关规定和申报信息

### 5.2 签证办理工具

- **签证中心官网**：如VFS Global、BLS International，提供在线预约、进度查询服务

- **携程/飞猪签证频道**：提供签证代办服务，方便快捷

- **支付宝/微信**：部分国家支持在支付宝或微信上申请电子签证

- **翻译软件**：如Google翻译、有道翻译官，用于翻译申请材料

### 5.3 紧急联系方式

- **外交部全球领事保护与服务应急热线**：+86-10-12308

- **中国驻外使领馆紧急电话**：可在中国领事服务网查询

- **当地报警电话**：可在入境时查看入境卡或咨询酒店工作人员

- **当地急救电话**：可在入境时查看入境卡或咨询酒店工作人员
