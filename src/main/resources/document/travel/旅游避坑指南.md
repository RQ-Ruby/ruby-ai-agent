# 旅游避坑指南

## 一、订机票
1. **避开周五晚 / 周日傍晚**返程，价格普遍上浮 30%+
2. 国际航线提前 6~8 周订价格最优；国内提前 2~3 周
3. 廉价航空（春秋、亚航、捷星）注意行李额，托运另收费
4. 中转票务必预留 ≥ 2.5 小时换乘时间，国际转国际预留 ≥ 3 小时

## 二、订酒店
1. 看「真实点评」而不是星级——同样 4 星，连锁更稳定
2. 警惕「最低价」：可能是无窗房 / 无早餐 / 不退不改
3. 直接酒店官网订房有时比 OTA 便宜 5%~10%，且房型可选更多
4. 预订前确认「免费取消时间节点」

## 三、跟团 / 一日游
1. 警惕「9.9 元一日游」「99 元长城八达岭一日游」——通常会强制购物
2. 选择有正规营业资质的旅行社，签订合同
3. 不要现金交付导游 / 司机，统一由旅行社平台收款

## 四、餐饮
1. 离主景点 200 米内的餐馆通常贵 30%~50% 且水准一般
2. 选大众点评 4.5 分以上、点评数 ≥ 200 的店
3. 海鲜市场加工：先确认「加工费」「损耗算法」，留好称重小票
4. 旅游区夜市：先看价格牌再下单

## 五、交通
1. 出租车 / 网约车要打表 / 显示订单价格，拒绝「拼车」议价
2. 高铁 / 火车站附近的「黑车」拒绝乘坐
3. 国外打车优先 Uber / Grab / 当地正规打车 App

## 六、消费陷阱
1. 「免费拍照」「免费试穿」往往是高价推销
2. 玉石、银器、字画在景区不要买
3. 刷卡注意币种，避免被「DCC」按人民币结算多收 3%~5% 汇率差
