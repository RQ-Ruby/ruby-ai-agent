# 北京 3 日经典攻略

## 适合人群
- 第一次到北京的游客
- 偏好历史文化、城市漫步、地道美食
- 预算中等（人均 2000~3500 元，含住宿）

## 行程概览

### Day 1 · 故宫中轴线
- 上午：天安门 → 故宫博物院（建议提前 7 天预约门票）
- 中午：王府井附近老字号（推荐：东来顺、四季民福烤鸭）
- 下午：景山公园俯瞰故宫全景
- 晚上：什刹海 / 南锣鼓巷夜游

### Day 2 · 长城与皇家园林
- 全天：八达岭长城（建议早 7 点出发避开人潮，自驾约 1.5 小时；公交 877 路约 1.5 小时）
- 傍晚回城：颐和园（夏季可看落日）
- 晚上：圆明园周边日料 / 海淀美食街

### Day 3 · 现代北京 + 博物馆
- 上午：国家博物馆（免费但需预约）
- 中午：前门大街老北京炸酱面
- 下午：798 艺术区
- 晚上：三里屯 / 工体

## 交通建议
- 市内：地铁为主，办一张「北京一卡通」或开通乘车码
- 长城：周边游推荐拼车 / 包车，比自驾停车更省心
- 机场：首都机场地铁线（25 元）/ 大兴机场线（35 元）

## 住宿推荐
- 第一次来：东城区前门 / 王府井附近，离主要景点近
- 商务：国贸 CBD
- 性价比：海淀五道口（地铁方便、餐饮多）

## 避坑提醒
1. 故宫、长城、国博周末与节假日必须**提前预约**，否则现场无法入园
2. 拒绝「黑车」「一日游低价拼团」，正规旅行社渠道更稳
3. 烤鸭店不是越贵越好，便宜坊、四季民福性价比高于全聚德
4. 夏季紫外线强，自带防晒；冬季室内外温差大，注意保暖
