# 旅游签证常见问答

## 1. 出境游需要多久办签证？
- 日本个人游：通常 5~7 个工作日，旺季可能延长至 10 天
- 韩国 C-3-9：5 个工作日
- 申根（法国 / 德国 / 意大利等）：建议提前 1 个月预约 VFS / TLS 中心
- 美国 B1/B2：面签预约时间不固定，从 2 周到 2 个月都有可能，**务必提前规划**
- 东南亚（泰国 / 马来 / 新加坡）：多数支持落地签或免签，确认护照有效期 ≥ 6 个月即可

## 2. 哪些国家对中国护照免签 / 落地签？
（信息会随政策调整，出行前务必查询最新外交部领事司公告）
- 免签：泰国、新加坡、马来西亚、阿联酋、马尔代夫、塞尔维亚等
- 落地签：印尼、柬埔寨、老挝、尼泊尔等

## 3. 申根签证需要的核心材料
1. 有效护照（有效期需覆盖回国后 3 个月）
2. 申根签证申请表
3. 近 6 个月银行流水（建议余额 3 万元以上）
4. 在职证明 / 在校证明
5. 机票订单 + 酒店订单（无需出票，提供「确认单」即可）
6. 旅行医疗保险（保额 ≥ 30 万欧元）
7. 行程单

## 4. 拒签常见原因
- 资料不齐 / 流水太少 / 大额转账无解释
- 行程不合理（例如 5 天跑 4 国）
- 在职证明信息不一致
- 历史出境记录不佳

## 5. 紧急加急怎么办？
- 大部分签证中心提供「加急服务」，加价 200~600 元，1~3 个工作日出签
- 美签可申请「加急面谈」（emergency appointment），但需提供紧急理由
